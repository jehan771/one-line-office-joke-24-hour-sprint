## About

Entry for the make.fun bounty [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162).

The program writes a single one-line joke about office life (at most 200 characters) to `/output/entry.txt`. The joke is a meeting about having too many meetings that runs over — so a follow-up gets scheduled to discuss why it ran over.

## Run

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` (no trailing newline).
